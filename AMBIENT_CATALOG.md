# Каталог фоновых анимаций PlanBoard

Живой список идей. **В коде сейчас** — колонка «Сейчас». Остальное — бэклог для смены мотива без ломки архитектуры (`motif` + `field` в `ambientProfiles.ts`).

Интенсивность везде одна: **выкл / слабо / сильно** — тот же мотив, другие плотность/яркость.

---

## Спрайты (PNG)

Ручная AI-генерация ассетов → `public/ambient/{id}.png` (+ `*-source.png`).
В рантайме canvas: `drawImage` (`ambientSprites.ts`). Процедурный fallback если PNG не загрузился.

Не путать с устаревшим `scripts/generate-ambient-sprites.mjs` (SVG) — для продакшн-вида используем сгенерированные картинки.

## Снежинки (Нордскол / GoT) — кристаллографические типы

Не «три разных осадка», а **привычки роста одного льда** (как в природе):

| ID | Имя | Визуал | Настроение |
|----|-----|--------|------------|
| `fern` | Папоротник / дендрит | Густые боковые ветки, «ёлочка» на каждом луче | Близкий план, крупные хлопья |
| `stellar` | Звёздная пластина | Шестиугольник-диск + тонкие лучи и насечки | «Ювелирная», блестящая |
| `needle` | Игла | Тонкие длинные лучи, мало веток | Дальний план, метель |
| `sectored` | Секторная | Широкие лопасти, почти цветок | Мягкий романтичный снег |
| `capped` | Колонна с шапкой | Короткая «гантель» / призма | Редкий акцент |
| `radiant` | Сияющая | Классика + вспышка блика при угле к «свету» | Магия, Нордскол |

**Сейчас в коде:** смесь `fern` / `stellar` / `needle` / `sectored` по глубине (близко = fern/stellar, далеко = needle). У GoT — те же типы, холоднее tint, реже.

**Идеи дальше:**
- Накопление «шуги» у нижнего края экрана (мягкий градиент, не куча)
- Порыв ветра: все хлопья на 0.8 с уходят вбок синхронно
- Одна «герой-снежинка» крупнее раз в N секунд (slow-mo ощущение)

## Кросс-палитровые «режимы атмосферы» (фантазия)

Идеи, которые можно повесить как опциональный слой позже (не вместо мотива):

1. **Breathing UI** — весь canvas чуть «дышит» opacity 2% (опасность для accessibility → только strong)
2. **Season clock** — зимой Нордскол гуще автоматически (уже частично `isWinterSeason`)
3. **Focus dim** — при открытой модалке анимация слабее (не отвлекает)
4. **Sound-reactive** *(нет)* — не делать без явного запроса
5. **Cursor wake** — частицы чуть расходятся от курсора (дорого, спорно)

## Как выбрать следующий эксперимент

1. Открыть этот файл → найти ID в таблице палитры  
2. Поставить `motif` / `field` в `ambientProfiles.ts`  
3. Добавить drawer в `AmbientBackground` / отдельный `ambient/*.ts`  
4. Слабо/сильно не трогать — только множители  

Правило: **один главный рассказ на палитру**. Варианты снежинок — исключение: это одна семья кристаллов, не разные эффекты.
